# 技術スタック / 環境の勘所（apps）

> セナ（実装役）の既定 reads。Emma 側で稼いだ実戦知を持ち込んである。

## 既定の選択（迷ったらこれ）

| 用途 | 既定 | 理由 |
|----|----|----|
| iPhone から使う小物 | **Web（静的HTML/JS）＋ iOS ショートカット** | App Store 申請・証明書・Mac が要らない。共有シートから叩ける |
| ホスティング | **Cloudflare Workers / Pages** | Emma 側で wrangler 運用の実績あり。無料枠で足りる |
| サーバ処理が要る時 | Cloudflare Workers（TypeScript） | 同上。常時起動サーバを持たない |
| 手元スクリプト | **Python 3**（標準ライブラリ優先） | 依存を増やさない |
| データ形式 | **JSON（BOMなしUTF-8・LF）** | `.gitattributes` で LF 強制済み |

**ネイティブiOSアプリ（Swift）は原則やらない。** Mac・証明書・審査が要り、趣味の回転速度が死ぬ。
どうしても必要になったら L2（advisor）で判断する。

## 環境の勘所（踏み抜きポイント）

- **cp932**：日本語Windowsの既定コンソールは cp932。CLI出力やファイルはUTF-8で扱い明示する（`encoding="utf-8"` / `PYTHONUTF8=1` / stdout張り替え）。
- **スクリプトはASCIIのみ**：`.cmd`/`.bat`/`.ps1` に日本語を混ぜると cp932 パースが崩れる。日本語は外部データへ逃がす。
- **JSON**：BOMなしUTF-8で保存／更新後は必ず parse 確認／Windowsパスの `\` は JSON文字列内で `\\`。
- **改行**：LF に統一（`.gitattributes`）。CRLF 混入は幽霊差分とハッシュ不一致の元。
- **PowerShellの表示だけで文字化け判断しない**（表示が化けているだけの場合がある。ファイル本体を見る）。
- **異常系に強く作る**：空応答・半端な行・タイムアウトで落とさない。

## 秘密情報の扱い（L3）

- API キー・トークン・Cookie は**コミットしない**。`.env`（gitignore 済み）か、Workers の Secrets に置く。
- 例を置くなら `.env.example` にキー名だけ書く（値は書かない）。
- ログ・コミットメッセージ・SPEC に秘密情報を貼らない。

## AIが閉じられない検証（＝ren にお願いする）

- iPhone 実機での動作・共有シート/ショートカットの挙動
- 実際のサービスアカウントでのログインが要る確認
- 外部公開（デプロイ後のURL疎通）

これらに当たったら、**手順書を書いて止める**。「たぶん動く」で完了にしない。
