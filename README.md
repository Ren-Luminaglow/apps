# apps — れんの趣味アプリ置き場

作りたいものを作る場所。仕事（Emma / task-system）とは切り離した実験場。

## 何が入っているか

```
apps/
├── CLAUDE.md            ← ★このリポの運用ルール（AIはまずこれを読む）
├── AGENTS.md            ← 他CLI（Codex等）向けの同内容ポインタ
├── .claude/agents/      ← サブエージェント（セナ/サラ/ニア/ミラ/レイ/アドバイザー）
├── docs/
│   ├── 技術スタック.md   ← このリポの標準構成・環境の勘所
│   ├── Lessons.md        ← 教訓ログ（失敗と再発防止）
│   └── アイデア置き場.md  ← 作りたいものの控え
└── apps/
    └── mahjong-paipu-export/   ← 雀魂 牌譜URL → JSON
```

## 開発の回し方（要約）

ボードやタスクシステムは持たない。**エマ（メインセッション）がオーケストレーター**として、
役を分けたサブエージェントに振る。詳細は `CLAUDE.md`。

- 発散したい → ミラ
- 裏取りしたい → ニア
- 指示を固めたい → レイ
- 実装 → セナ
- 品質ゲート → サラ
- 方針が割れた → アドバイザー（L2裁定）

進行状況は board ではなく、**各アプリの `SPEC.md` / `CHANGELOG.md`** に残す。

## アプリの置き方

```
apps/<app-name>/
├── README.md      ← 何・どう動かす
├── SPEC.md        ← 受け入れ条件（サラのレビュー基準になる）
├── CHANGELOG.md
└── src/ …
```
